# USB-HID-Converter
A simple device that converts UART commands to USB-HID commands


## Overview
Have you ever wished your old Arduino could do more than blink LEDs? The USB-HID-Converter adds a new use for boards and other devices with UART support. It converts their serial input into USB human interface device (HID) controls, which a computer can recognize as input from a keyboard, mouse, or gamepad. That means a project can send keystrokes, move a pointer, or trigger game controls instead of only turning lights on and off. The converter gives older hardware a simple way to interact with a computer using familiar input devices.
